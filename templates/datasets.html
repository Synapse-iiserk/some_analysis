Methodology & Data Pipeline

Data Collection

31 datasets fetched via data.gov.in API using curl (Python requests times out on this API). 9 World Bank indicators via REST API. All data saved as JSON, processed to CSV.

Feature Engineering

Macro features aligned to monthly frequency. Lag features (1-12 months). Rolling statistics. Seasonal decomposition. Trade balance computed from export/import totals.

Model Training

Train/test split: 265 months training, 24 months test. 5 models: SARIMAX (auto-ARIMA), XGBoost (500 trees), LightGBM (500 trees), VAR (4 lags), ensemble average. All trained on 12 CPU cores.

Scenario Analysis

3 scenarios: Base (crude $84-88, INR 96-100), Bull (crude $65-70, INR 85-86), Bear (crude $95-110, INR 97-105). 12-month projections with monthly granularity.
